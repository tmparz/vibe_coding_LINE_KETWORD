# 課前 30 分鐘檢查表（老師版）

上課前一週和每位學員各約一次，視訊或碰面都可以。目的是把**帳號、付款、安裝**這三件最花時間的事，在上課前全部處理完。

每位學員都檢查同樣的項目。

| 檢查項目 | 時間 | 學員 1 | 學員 2 | 學員 3 |
|---|---|---|---|---|
| 1. 電腦：自己的電腦、能安裝軟體、有管理員權限 | 3 分 | ☐ | ☐ | ☐ |
| 2. Google：能登入 AI Studio | 2 分 | ☐ | ☐ | ☐ |
| 3. LINE：手機已登記 Email，記得密碼 | 3 分 | ☐ | ☐ | ☐ |
| 4. **建立 LINE 官方帳號**，手機加好友 | 6 分 | ☐ | ☐ | ☐ |
| 5. ChatGPT：已訂閱 **Plus**（不是 Go 或免費版） | 2 分 | ☐ | ☐ | ☐ |
| 6. Codex App：已安裝，已用同一個帳號登入；ChatGPT「為所有人改善模型」已關閉 | 5 分 | ☐ | ☐ | ☐ |
| 7. Cloudflare：已完成 Email 驗證，能登入 | 2 分 | ☐ | ☐ | ☐ |
| 8. **實測 skill：**讓 Codex 跑一次 Cloudflare 授權 | 5 分 | ☐ | ☐ | ☐ |
| 9. 作業：寫好 5 個「客人會問的問題」 | 2 分 | ☐ | ☐ | ☐ |

## 每一項的檢查重點

**1. 電腦**
- 帶公司電腦的學員，很可能沒辦法安裝軟體，或公司網路擋掉 Cloudflare。請在這時候確認，必要時請學員改帶自己的電腦。
- 確認電腦的帳號有管理員權限。Codex 透過 skill 安裝工具時，Windows 可能會跳出「是否允許變更」的視窗，沒有權限就會卡住。

**3. LINE Email 登記**
- 很少用電腦的學員最常卡在這一步：手機 LINE 從來沒設定過 Email，或忘了密碼。請陪學員在手機上設定好。

**4. 建立 LINE 官方帳號**
- 用電腦登入 <https://manager.line.biz/>，照 [申請步驟](https://tmparz.github.io/vibe-coding-course-guide/line-official-account-setup-guide.html#apply) 建立一個官方帳號。名稱用學員自己的服務主題（和第 9 項作業同一個），之後也可以改。
- 建立完請學員用手機加這個官方帳號為好友，確認收得到預設的歡迎訊息。
- **只建立帳號就好。**歡迎訊息、關鍵字、開通 Messaging API 都留到第一天下半場一起做，學員才知道每一步在做什麼。
- 為什麼不留到上課再建：申請表要填產業類別、地區，第一次填的人常停在這裡想很久；三個人同時建，也可能遇到簡訊驗證或審核等待。

**5. ChatGPT Plus**
- 請學員打開「設定 → 帳號」截圖，確認顯示的是 **Plus**。ChatGPT Go 在台灣比較便宜，學員可能誤選。
- 用家人信用卡付款的學員，請先和家人說明，避免之後看到外幣扣款以為被盜刷。
- 提醒取消訂閱的方式，並在學員的行事曆上設定扣款日前一天提醒。

**8. 實測 skill（最重要）**
- 用課程的 Cloudflare skill，讓 Codex 執行到「**打開瀏覽器授權 Cloudflare**」這一步為止，確認授權成功就好，不需要部署。
- 課前跑過一次授權，上課時學員就會認得這個畫面，也能先發現電腦權限或防毒軟體的問題。

**9. 作業**
- 看一下學員寫的 5 個問題。主題不限，第一天頁面「我的 FAQ」分頁有三個範例（手作甜點、室內裝修工程、設計接案），所有學員看到的都一樣。
- 想不到主題的學員，直接用「手作甜點」範例，上課照樣能走完全部流程。

## 上課前一天

- [ ] 用 LINE 群組提醒：帶筆電、充電線、充飽電的手機、記得 ChatGPT、LINE、Cloudflare 的密碼。
- [ ] 老師自己用全新帳號把第一天的流程完整跑一次，確認 skill、Codex、LINE、Cloudflare 都沒有改版；特別是第一天的部署提示詞，Codex 能不能照著做完。
- [ ] 準備備援：老師自己的示範機器人，可以讓學員先用手機加好友體驗。萬一學員的部署失敗，至少能完成「同一題比兩次」的體驗。
