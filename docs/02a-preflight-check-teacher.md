# 課前 30 分鐘檢查表（老師版）

上課前一週和每位學員各約一次，視訊或碰面都可以。目的是把**帳號、付款、安裝**這三件最花時間的事，在上課前全部處理完。

學員：A（會用 AI 作圖）／B（媽媽，零基礎）／C（行政，零基礎）

| 檢查項目 | 時間 | A | B | C |
|---|---|---|---|---|
| 1. 電腦：自己的電腦、能安裝軟體、有管理員權限 | 3 分 | ☐ | ☐ | ☐ |
| 2. Google：能登入 AI Studio | 3 分 | ☐ | ☐ | ☐ |
| 3. LINE：手機已登記 Email，記得密碼 | 5 分 | ☐ | ☐ | ☐ |

| 6. Cloudflare：已完成 Email 驗證，能登入 | 3 分 | ☐ | ☐ | ☐ |

| 8. 作業：寫好 5 個「客人會問的問題」 | 3 分 | ☐ | ☐ | ☐ |

## 每一項的檢查重點

**1. 電腦**
- 學員 C 如果帶公司電腦，很可能沒辦法安裝軟體，或公司網路擋掉 Cloudflare。請在這時候確認，必要時請她改帶自己的電腦。
- 確認電腦的帳號有管理員權限。Codex 透過 skill 安裝工具時，Windows 可能會跳出「是否允許變更」的視窗，沒有權限就會卡住。

**3. LINE Email 登記**
- 學員 B 最可能卡在這一步：手機 LINE 從來沒設定過 Email，或忘了密碼。請陪她在手機上設定好。
- 設定完後，請她實際用電腦登入一次 <https://manager.line.biz/>，確認登得進去。**課前只要能登入就好，建立官方帳號留到上課一起做。**

**4. ChatGPT Plus**
- 請學員打開「設定 → 帳號」截圖，確認顯示的是 **Plus**。ChatGPT Go 在台灣比較便宜，學員可能誤選。
- 學員 B 如果用家人的信用卡，請她先和家人說明，避免之後看到外幣扣款以為被盜刷。
- 提醒取消訂閱的方式，並在學員的行事曆上設定扣款日前一天提醒。

**7. 實測 skill（最重要）**
- 用課程的 Cloudflare skill，讓 Codex 執行到「**打開瀏覽器授權 Cloudflare**」這一步為止，確認授權成功就好，不需要部署。
- 課前跑過一次授權，上課時學員就會認得這個畫面，也能先發現電腦權限或防毒軟體的問題。

**8. 作業**
- 看一下學員寫的 5 個問題。問題主題可以參考：
  - A：設計或作圖接案（報價、交件時間、修改次數）
  - B：【老師決定，例如手作小店或團購】
  - C：工程公司回覆業主（施工時間、保固、報價流程）
