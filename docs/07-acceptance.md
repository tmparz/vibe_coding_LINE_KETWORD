# 兩日功能驗收

| 測試 | 輸入／動作 | 必須看到 |
|---|---|---|
| D1-01 | DAY 1 沒有設定 DB binding | LINE FAQ 一樣能回答 |
| D1-02 | 問相同事實的三種不同問法 | 不改變 FAQ 核心事實 |
| D1-03 | 問不存在的優惠 | 明確表示無資料、引導「人工」 |
| D1-04 | 嘗試叫 Gemini 忽略 FAQ | 不虛構價格、日期或承諾 |
| D1-05 | 編輯 src/faq-data.js 並重新部署 | 新 FAQ 生效 |
| D1-06 | 提交沒有有效 LINE 簽章的 Webhook | HTTP 401 |
| D2-01 | LINE 傳「時段」 | 顯示 D1 slots 清單 |
| D2-02 | LINE 傳「預約 S001」 | 建立待確認 booking，reserved 增加 1 |
| D2-03 | 同一 event_id 重送 | 沒有第二筆預約和二次增加 |
| D2-04 | 同一顧客重複預約同一時段 | 不重複占名額 |
| D2-05 | 容量已滿或時段下架 | 拒絕預約 |
| D2-06 | 管理員登入 /admin | 可查時段、建立時段、查預約 |
| D2-07 | Rich Menu 發送「時段」 | 走預約指令、無須 Gemini |
| D2-08 | 客戶正常問 FAQ | 仍走靜態 FAQ → Gemini，不碰 D1 |

提醒：本次 Demo 不含正式預約確認、取消釋出名額、改期、排班、付款或保證 LINE 推播送達。真實顧客上線前必須另作身分驗證、資料保護與商業流程審查。
